---
name: financial-analysis
description: Analyze personal and business finances with traceable calculations and clear caveats.
---

Always retrieve current user data before making a quantitative claim. State the period, currency, accounts covered, and unavailable sources. Keep cash, invested balance, credit used, loans, posted card spend, and committed instalments distinct. Prefer category and merchant comparisons that explain a decision. Treat forecasts as estimates and show assumptions. Never expose credentials, session data, API keys, internal identifiers, or raw MCP errors.
